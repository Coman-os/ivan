# Иван

Помощник руководителя. Всё, что умеет Иван, накопительно: (1) уместно уточняет при неоднозначности и выполняет так, что не надо переделывать; (2) различает своё и чужое — вычислимое и обратимое закрывает сам с пояснением, наверх несёт только то, что требует вашего слова; (3) возражает по делу — называет допущения, останавливает опасное, требует цену идеи, идёт к первоисточнику вместо пересказа. Со временем из помощника становится напарником, с которым думают.

## Установка

```
/plugin marketplace add <путь-или-репозиторий>
/plugin install coman-ivan
```

Или локально для проверки: `claude --plugin-dir <путь-к-этой-папке>`

## Ограничение платформы — прочитать до установки

Плагин Claude Code **не доставляет `CLAUDE.md`** как контекст проекта
(«plugins contribute context through skills, agents, and hooks rather than
CLAUDE.md» — документация). В родной установке харнеса правила Ивана живут
именно в `CLAUDE.md` и грузятся **каждую сессию автоматически**.

Здесь они упакованы навыком `ivan-rules` — но **ограничение закрыто**: хук
`session_start_load_rules.py` на событии `SessionStart` впрыскивает тело правил
в контекст **безусловно, при старте каждой сессии**. Просить Claude прочитать
навык вручную не нужно.

Остаточная разница с родной установкой: правила приходят как контекст сессии,
а не как файл проекта — на поведение это не влияет, но при отладке искать их
надо в выводе хука, а не в `CLAUDE.md`.

Хуки, в отличие от GPT Work-сборки, едут **исполняемыми**: транспорт
enforcement на этой платформе подтверждён (same-vendor).
