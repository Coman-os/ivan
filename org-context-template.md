# Контекст организации

> **Кому нужно.** Когда Ивана ставят несколько человек в одной компании. Без этого слоя каждый пишет общее заново — и пятеро расходятся в деталях: у одного клиент называется «Сбер», у другого «Сбербанк», третий не знает, что квартальные цифры конфиденциальны.
>
> **Как работает.** Файл `ORG-CONTEXT.md` в корне рабочей папки. Иван читает его **первым**, личную карточку — поверх. Наложение, не замена: чего нет в личной, наследуется отсюда.
>
> **Заполняет** — один человек за компанию (обычно тот, кто внедряет). Остальные не дублируют это в своих карточках.

## Что сюда НЕ кладётся

| Не сюда | Куда |
|---|---|
| Роль и задачи конкретного человека | его `WORKING-AGREEMENT.md` |
| Класс петли по видам работ | его `WORKING-AGREEMENT.md` — у каждого свой |
| Настройки тона и длины ответа | его `WORKING-AGREEMENT.md` |
| Правила поведения Ивана (когда возражать) | не настраивается — это фигура |

Признак: **если у двух сотрудников значение разное — это личная карточка, не общий слой.**
