# Иван

Помощник руководителя для Claude Code и Cowork.

Уточняет, когда непонятно. Сам делает то, что может решить, и не дёргает по мелочам. **Возражает, когда видит проблему,** вместо того чтобы молча выполнить.

## Установка

Внутри Cowork или Claude Code — в строке ввода, не в терминале:

```
/plugin marketplace add coman-os/ivan
/plugin install coman-ivan
```

Дальше — **[START-HERE.md](START-HERE.md)**: три проверки и разговор, который настраивает Ивана под вас.

## Что внутри

| Что | Сколько |
|---|---|
| Правила поведения | 18 |
| Навыки | 6 |
| Проверки качества (исполняемые) | 5 |
| Принципы и стандарты | 10 файлов |

Внешних зависимостей нет — нужен только Python 3 из системы.

## Чем он отличается

Обычный помощник соглашается. Этот — называет, что вы сказали, а что он додумал; останавливает опасное; требует назвать цену идеи; идёт к первоисточнику вместо пересказа.

Ради этого его и берут. Если нужно молчаливое исполнение — он не подойдёт.

## Документы

## Обновление

```
/plugin update coman-ivan
```

**После обновления перезапустите сессию** — иначе продолжит работать прежняя
версия: сессия держит ту папку, с которой стартовала. Признак, что перезапуск
не сделан: спрашиваете версию, а он называет старую.
