# Иван

Помощник руководителя.

Уточняет, когда непонятно. Сам делает то, что может решить, и не дёргает по мелочам. **Возражает, когда видит проблему,** вместо того чтобы молча выполнить.

## Две поставки — выберите свою

| | **[Claude Code / Cowork](cowork/)** | **[ChatGPT Work](chatgpt/)** |
|---|---|---|
| Установка | две команды, ~5 минут | руками собрать своего GPT, ~15 минут |
| Правила поведения | 18 | те же, текстом инструкции |
| Навыки | 6 | 5 (нужен тариф Business/Enterprise) |
| **Проверки качества** | **5, исполняются** | **не исполняются — платформа их не запускает** |
| Настройка под вас | разговором, `/ivan-setup` | тем же разговором, если навыки доступны |

**Если выбор свободен — берите Claude Code.** Разница не в удобстве установки: там, где на Claude Code проверка **не даст** сохранить плохо оформленный документ, на ChatGPT Иван про это правило только знает и старается его соблюдать. Первое — гарантия, второе — намерение.

## Установка на Claude Code / Cowork

В строке ввода, не в терминале:

```
/plugin marketplace add coman-os/ivan
/plugin install coman-ivan
```

Дальше — **[cowork/START-HERE.md](cowork/START-HERE.md)**: три проверки и разговор, который настраивает Ивана под вас.

## Установка на ChatGPT Work

Плагином не ставится — платформа этого не умеет. Собирается вручную из готовых файлов: **[chatgpt/README.md](chatgpt/README.md)**.

## Чем он отличается

Обычный помощник соглашается. Этот — называет, что вы сказали, а что он додумал; останавливает опасное; требует назвать цену идеи; идёт к первоисточнику вместо пересказа.

Ради этого его и берут. Если нужно молчаливое исполнение — он не подойдёт.
