# Иван

Помощник руководителя.

Уточняет, когда непонятно. Сам делает то, что может решить, и не дёргает по мелочам. **Возражает, когда видит проблему,** вместо того чтобы молча выполнить.

## Две поставки — выберите свою

| | **[Claude Code / Cowork](cowork/)** | **[Codex / ChatGPT Work](chatgpt/)** |
|---|---|---|
| Установка | две команды | две команды в консоли |
| Правила поведения | 21, грузятся каждую сессию | 21, грузятся каждую сессию |
| Навыки | 6 | 6 |
| Проверки качества | 5, работают сразу | 6, каждую надо подтвердить |
| Настройка под вас | разговором, `/ivan-setup` | тем же разговором |

Содержимое одинаковое: те же правила, те же навыки, те же проверки. Различаются установка и одна вещь, о которой ниже.

## Установка на Claude Code / Cowork

В строке ввода, не в терминале:

```
/plugin marketplace add coman-os/ivan
/plugin install coman-ivan-cowork
```

Дальше — **[cowork/START-HERE.md](cowork/START-HERE.md)**: три проверки и разговор, который настраивает Ивана под вас.

## Установка на Codex / ChatGPT Work

В консоли:

```
codex plugin marketplace add coman-os/ivan --ref main
codex plugin add coman-ivan-codex@coman
```

Навыки становятся доступны со следующей сессии — начните новую после установки.

**Одно отличие, которое стоит знать заранее.** Codex не запускает проверку, пока вы её не подтвердили — командой `/hooks`. Это касается и той, что загружает правила: без подтверждения Иван будет знать лишь малую их часть. Подтверждение привязано к содержимому файла, поэтому после обновления поставки его придётся дать заново.

В приложении ChatGPT команд выше нет — там плагин ставится из каталога либо из маркетплейса рабочего пространства, который подключает администратор. Если ни того ни другого пока нет, соберите вручную: **[chatgpt/README.md](chatgpt/README.md)**.

## Чем он отличается

Обычный помощник соглашается. Этот — называет, что вы сказали, а что он додумал; останавливает опасное; требует назвать цену идеи; идёт к первоисточнику вместо пересказа.

Ради этого его и берут. Если нужно молчаливое исполнение — он не подойдёт.
