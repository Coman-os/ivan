## Типы документов и статусы

- **Стратегические / операционные:** owner + статус (🚧 Draft → ✅ Active → 📦 Archived).
- **Контент:** 🚧 Draft → ✏️ Editing → 👀 Review → ✅ Published (финальный, без Archived).
- **Идеи:** статус на уровне строки (💡 → ✅ / ❌ / ⏸️).
- **Справочники / журналы:** статус не нужен, достаточно даты.
- **Встречи:** обязательна ссылка на расшифровку во внешнем канале хранения (расшифровки — в канале, выжимки — в hub).
- **Research:** 🚧 Draft → ✅ Complete → 📦 Archived (Complete = выводы + источники верифицированы).
- **Explorations:** 🚧 Draft → ✅ Complete → 📦 Archived (Complete = выводы + инсайты + экшен-план).
- **Experiments:** 🧪 Hypothesis → 🔬 Running → ✅ Concluded → 📦 Archived (Concluded = результаты + выводы + решение).
- **Команда (`{client}-knowledge-hub/teams/{team}/`):** ✅ Active → 📦 Archived. Архивация = `git mv` в `_archive/` + статус `📦 Archived` с датой закрытия. Данные сохраняются для ретроспективы.
  - **`teams/{team}/workspace/`** — плоская папка work-in-progress артефактов команды (drafts, reports, experiments, reference-data). Подпапки возникают демандово (≥10 файлов одного типа), не угадываются заранее. Синхронизация (pipeline) `workspace/` игнорирует. Lifecycle артефакта: draft → согласование (если применимо) → merge в целевой документ → старый draft → `_changes/` (history).

## README (навигационный индекс)

Каждая папка с .md-документами обязана иметь `README.md` с индексом. Формат:

```markdown
# [Название папки]

| Документ | Статус | Описание | Обновлён |
|----------|--------|----------|----------|
| file.md | ✅ Active | Краткое описание | 2026-03-25 |
| subfolder/ | — | Описание (N документов) | 2026-03-25 |
```

Статус и дата — из метаданных файла (таблица `| Параметр | Значение |`); если метаданных нет — `❓ No metadata`. README поддерживается hook'ом `post_write_readme_sync` и проверяется при `cmn:kh-check`.

## Sandbox-документы (`_sandbox/`)

Место разработки. Lifecycle: создаётся как `experimental` / `draft` → при принятии — promotion через `git mv` в целевую папку со `status: accepted` + `promoted_from:` + переписанными внешними ссылками. Содержит ТОЛЬКО experimental / in-progress / accepted-pending-impl.
