# Иван — установка в ChatGPT Work

**Версия:** 0.8.0

## Что внутри
- `instructions.txt` — системная инструкция (≤8000 символов) → в поле Instructions custom GPT.
- **4 навыка** (`skills/`) — устанавливаются вместе с плагином.
- **10 knowledge-файлов** (`knowledge/`) — принципы и стандарты → в раздел Knowledge.
- `.codex-plugin/plugin.json` — манифест плагина.

## Как установить (без разработчика)
1. В ChatGPT Work: **Создать custom GPT** (GPT Builder → Configure).
2. **Instructions:** открой `instructions.txt`, скопируй весь текст в поле «Instructions».
3. **Knowledge:** загрузи все файлы из папки `knowledge/` в раздел «Knowledge».
4. **Skills:** если рабочее пространство поддерживает Skills (Business/Enterprise) — загрузи папки из `skills/` как навыки; иначе пропусти (их логика частично отражена в инструкции).
5. **Сохрани / опубликуй** для себя или рабочего пространства.

## Важное ограничение платформы
На ChatGPT Work **не работают enforcement-хуки** (авто-проверки качества, которые
есть в Claude Code): платформа их не исполняет. Поэтому дисциплина качества
(разбор ошибок по формату, factual integrity, единое оформление) держится
**только текстом инструкции** — она вероятностна, не гарантирована как хук.
Это ожидаемо для теста; полный enforcement — на платформах с хуками.

## Что проверить в тесте
- Дай задачу с неоднозначностью → уместно ли Иван уточняет (не молча угадывает)?
- Дай задачу оформить документ → следует ли структуре/языку/метаданным?
- Спроси «почему так вышло» → отвечает ли по формату (Где сбой / Почему / Что починить)?
- Дай факт, которого нет в источнике → не выдумывает ли, помечает ли TBD?
