# Проверка поставки

В корне распакованного репозитория выполните:

```bash
python3 -B -m unittest discover -s tests -v
```

Тесты не отправляют обращения и не требуют учётки. Они проверяют настоящие
манифесты обеих сборок, адреса обновлений, предпросмотр публикаций,
заголовки авторизации и точное восстановление стартового текста из частей.
Ошибка проверки возвращает ненулевой код завершения.

Локальный зелёный прогон не доказывает доставку текста в контекст Cowork.
Для этого нужна отдельная проверка после установки новой сборки.

## Новая задача Cowork

Установите подготовленный пакет `coman-ivan-cowork-3.0.0.zip` штатным способом
установки локального плагина вашей версии Cowork. Начните новую задачу;
продолжение прежней задачи для этой проверки не подходит.

Первым сообщением отправьте:

```text
Проверяем доставку правил при старте.

До ответа не открывай файлы и не вызывай инструменты.
Найди в уже полученном контексте блоки «[Иван: часть …]».
Перечисли номера всех доступных частей и указанное общее число.
Для каждой части процитируй последние 80 символов дословно.
Сообщи о пропущенных номерах, повторениях и сообщении
«Правила Ивана НЕ ЗАГРУЖЕНЫ полностью».
Не восстанавливай отсутствующий текст по догадке.
```

Сохраните ответ. Затем разрешите помощнику инструменты отдельным сообщением:

```text
Теперь проверь предыдущий ответ по установленной сборке.
Прочитай её BUILD-MANIFEST.json и hooks/hooks.json. Назови версию.
Найди зарегистрированные команды session_start_load_rules.py.
Выполни их с теми же аргументами и рабочей папкой, что при старте.
Сопоставь последние 80 символов каждого непустого блока с цитатами
из предыдущего ответа. Не исправляй предыдущие цитаты задним числом.
Для каждой части покажи «совпало» или точное расхождение.
```

Приёмка: установлена ожидаемая версия; все непустые части доступны без
предварительного чтения файлов; каждая цитата совпадает; сообщения о неполной
загрузке нет. Число частей зависит от размера договора и контекста организации.
Наличие одного номера последней части не доказывает полноту.

Повторите в ещё одной новой задаче. До этих проверок обращение №33 остаётся
открытым. При расхождении сохраните оба ответа и версию; перед публичной
публикацией уберите цитаты из личного договора и любые частные данные.

## Границы проверок

- Свод доставляется без сокращений. Если контекст превышает ёмкость частей,
  первая часть сообщает отказ и требует чтения исходников; полная доставка
  в таком случае не заявляется.
- Проверка секретов распознаёт известные форматы, но не все имена и частные
  сведения. Отпечаток предпросмотра подтверждает текст, а не согласие человека.
- По №30 распознанный вопрос о публикации или изменении утверждённого правила
  проходит без повтора, если необходимость согласия уже объяснена. Необычная
  формулировка может вызвать дополнительный проход. При разборе сессий
  учитывайте лишние вопросы, прошедшие исключение. №30 остаётся под наблюдением:
  исправление снимает повтор только для распознанных объяснений.
